# Scope and implementation

Exact GF(2) Vietoris–Rips H0/H1 persistence for at most 24 points in 1–4 dimensions. Filtration uses maximum edge length. Triangles suffice to compute H1; H2 is deliberately omitted. Unpaired intervals are right-censored, not proven infinite. A deterministic matched leave-one-out nearest-centroid comparison uses training-only feature scaling. No external empirical benefit is established.

The code implements a bounded reference method, not a new universal theory. Source and method versions, declared inputs and explicit limitations must accompany downstream claims. Domain test success does not substitute for independent reproduction. Changes to captured evidence reopen dependent claims through the ResearchOS controller.
